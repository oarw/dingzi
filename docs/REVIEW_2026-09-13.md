| P1 | 文档要求清空密码哈希恢复密码，原代码却没有生成新密码；错误的非空哈希也会被接受进入启动 | [main.go](../cmd/server/main.go) 空哈希生成并原子保存新密码，保留注册密钥；无效非空哈希拒绝启动且不覆盖配置；测试恢复、重启和损坏文件 |
| P2 | 已连接但从不上报指标的 Agent 一直在线；30 秒采样间隔又可能在下一次正常上报前被判离线 | [hub.go](../internal/server/hub.go) 同时检查首报期限和最近指标，超时为 `max(30 秒, 3 × 采样间隔)`；覆盖首报、慢采样及重连不能复活过期指标，单机与列表一致 |
| P2 | UTC 月界前后使用非 UTC 时间计算账期，周期可能随面板时区变化 | [traffic.go](../internal/server/traffic.go) 的 `CycleStart` 统一转 UTC；覆盖 UTC+8 与 UTC−7 跨月用例 |

| P2 | 机器详情的流量一直把入站、出站相加，与 `out` / `max` 配额口径不一致 | [app.js](../internal/server/web/app.js) 与看板复用计费函数；浏览器用受控数值检查 `sum/out/max` |
| P2 | Webhook 切换到 Telegram 时，界面仍提示可保留旧类型 token，允许不填必需的 Bot Token | [app.js](../internal/server/web/app.js) 只在类型不变时保留凭据提示；切换类型同步必填项；浏览器验证已存 token 不回显及类型切换 |
| P2 | 安装脚本接受 ARMv6，但构建矩阵未设置 `GOARM`，本地复核原 ARM 产物为 `GOARM=7` | [CI](../.github/workflows/ci.yml) 和 [发布矩阵](../.github/workflows/release.yml) 显式使用 `GOARM=6`，仍保留原资产名 |

| P2 | 手动发布的下拉选项含空字符串，actionlint 报 `string should not be empty` | [release.yml](../.github/workflows/release.yml) 改为显式 `auto` 默认选项；验证自动推断、强制版本级别与仅文档提交跳过发布 |
